🧠 Cosmos VLM: Dual-Input Semantic Fusion Graph

This graph explicitly shows how the VLM simultaneously looks at the global environment map (Gaussian Splat) and the local dynamic camera data (Ego-RGB + Keypoints) to make a social navigation decision.

Global Environment Static

LCD-Splat / AG-SLAM Map
A dense, persistent 3D Gaussian Splatting map of the conference room. All dynamic humans have been erased via Masking.

Ego-Centric Camera Dynamic

RealSense RGB
The live, front-facing camera feed showing the immediate surroundings and currently visible pedestrians.

Human Keypoints Metadata

LV-DOT Bounding Boxes
Skeletal keypoints (gaze, velocity) extracted by YOLOv11 running on the Orin NX.

Spatial Query Render Render Engine

Given the prompt "Find a booth", the GPU renders a 2D top-down semantic costmap crop from the 3D Gaussian Splat to feed the VLM.

Visual Tokenizer ViT-L

Compresses the raw RGB camera frame into dense visual embeddings.

Geometric Projector MLP

Encodes the bounding boxes and 3D velocity vectors into the same latent space as the visual tokens.

Cosmos 3 Nano (16B) - Mixture of Transformers

The model attends to all three latent streams simultaneously. It uses the Spatial Render to understand global routing (where the booth is), the RGB Tokens to see the crowd, and the Keypoints to infer social intent (who is looking at me).
