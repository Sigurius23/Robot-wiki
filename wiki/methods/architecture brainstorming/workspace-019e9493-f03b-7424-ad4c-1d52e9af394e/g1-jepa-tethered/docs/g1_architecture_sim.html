Engineering comparison

Choose each method by the query it must answer

The stack separates metric safety, learned prediction, visual reconstruction, and task reasoning. That avoids asking a visually convincing map to make a claim it cannot certify.

Representation decision

Use occupancy and ESDF for local safety, sparse voxels for prediction, 3DGS for visual-semantic context, and a scene graph for task reasoning.
