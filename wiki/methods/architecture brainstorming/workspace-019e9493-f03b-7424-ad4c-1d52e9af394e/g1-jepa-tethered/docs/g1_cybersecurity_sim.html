Empirical security audits of factory Unitree G1 firmware revealed zero-day BLE command injection vectors, static cryptographic keys, and unencrypted MQTT telemetry leaks at 1.03 Mbps. Explore the attack surface and our local air-gapped hardening architecture.

🚨 Factory Vulnerability Summary (Vilches et al. 2025 — arXiv:2509.14139)

Unpatched factory G1 units expose an unauthenticated BLE provisioning daemon with a fleet-wide static AES-CFB key, allowing remote root command execution via ";$(cmd);#" injection strings.

1. BLE Provisioning Injection (UniPwn)

Critical

The factory BLE daemon accepts unvalidated SSID/password strings. Injecting ";$(cmd);#" executes arbitrary shell commands as root. Encrypted with a fleet-wide static AES-CFB key.

  • Unauthenticated remote root code execution
  • Static encryption key across all sold G1 units
  • Exploitable within 15 meters via BLE scanner

2. Obfuscated FMX Protocol

High

Internal motor/sensor telemetry uses FMX encrypted with Blowfish-ECB and a static 128-bit key. Relies on LCG for obfuscation, violating Kerckhoffs's principle.

  • Replay attacks on joint motor actuation
  • Static Blowfish-ECB key reverse-engineered
  • Insecure LCG PRNG sequence prediction

3. 300s Telemetry Ping & Cloud Drain

High

Factory units transmit 300-second multimodal telemetry (battery, joint torque, camera/mic data) to 43.175.228.18:17883 at 1.03 Mbps with auto-reconnect.

  • Violates GDPR Articles 6 & 13 (no consent)
  • Exposes room layout & camera metadata
  • Mitigated via /etc/hosts null-routing

4. CloudSail AI Backdoor & 39C3 Congress

Critical

Confirmed by 39C3 Hacker Congress and Benn Jordan: CloudSail remote management allows RCE and prompt-injections into onboard embodied AI.

  • Remote LLM/VLA prompt injection vector
  • Bypasses local user permission models
  • Hardened via wired Ethernet host-routed NAT
